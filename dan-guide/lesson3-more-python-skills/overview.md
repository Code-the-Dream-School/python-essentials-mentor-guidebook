# Lesson 3: More Python Skills – Mentor Guide

This session builds on earlier lessons by combining conditional logic with loops and recursion. I like to walk through practical examples that reinforce how logic flows through nested blocks and how function calls can be used to break down problems.

---

## Topics I Like to Emphasize

- Chained vs nested conditionals  
- Simplifying conditionals using Boolean expressions  
- Writing a chained `if/elif/else` structure  
- Writing a recursive function  
- Accepting and validating user input using `input()`

---

## Common Pitfalls

- Not using `return` correctly in recursion  
- Overusing nested `if` statements  
- Forgetting that `input()` returns a string  
- Infinite recursion without a clear base case  

---

## Sample Prompts for Discussion

- What’s the difference between `if/elif` and nested `if` blocks?  
- When is recursion a better choice than a loop?  
- How can you safely use user input in a numeric function?
