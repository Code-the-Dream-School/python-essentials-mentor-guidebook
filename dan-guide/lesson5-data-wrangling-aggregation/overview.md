# Lesson 5: Data Wrangling and Aggregation

## How to Use code.py

This script walks through key data wrangling and aggregation concepts using sample data.

### To run:

1. Activate your virtual environment.
2. Open your terminal in this lesson folder.
3. Run: python code.py
4. Press Enter when prompted to continue through each section.

Topics include:
- Series and indexing
- Creating and modifying DataFrames
- Loading and combining CSV and JSON
- Viewing and inspecting data
- Grouping and aggregating
- Merging and joining
- Data cleaning and transformation

Use this script to live-demo or explore the lesson interactively.
