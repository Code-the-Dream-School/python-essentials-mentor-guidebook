## Setup Instructions (from `dan-guide` root)

### macOS / Linux  
python3 -m venv .venv  
source .venv/bin/activate  
pip install -r requirements.txt

### Windows  
python -m venv .venv  
source .venv/Scripts/activate  
pip install -r requirements.txt
