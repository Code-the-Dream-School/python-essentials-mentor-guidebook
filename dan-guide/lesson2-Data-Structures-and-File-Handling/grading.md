Grading Guide – Assignment 1: Introduction to Python

Grading Steps

Open the Submission  
Go to https://classes.codethedream.org/mentor/dashboard  
Locate the student's submission for Assignment 2 
If the student submitted a GitHub Pull Request:  
Open the PR  
Review the assignment2.py file  
Compare it to the mentor version if needed

Run Tests  
The assignment uses pytest to verify correctness.

Navigate to the assignment1 directory  
Inside the venv  
Run the following command in terminal:

  pytest -v -x assignment2-test.py

All tests must pass  
If any test fails, review the corresponding function in assignment1.py

Review for Completeness  
Ensure the student completed all 10 tasks  

Provide Feedback  
Point out anything missing or incorrect  
Use GitHub comments or submit feedback through the mentor dashboard

Mark the Assignment  
If all tests pass and the work matches the instructions, mark it complete by following the airtable link on the mentor dashboard and complete the form  
If not, request changes and allow resubmission
