## Lesson 0: Learning to Learn – Mentor Checklist

- Ask students if they’ve read the Student Handbook
- Confirm handbook quiz is completed (self-graded)
- Confirm Study Plan has been submitted as a PDF
- Talk about:

  - How they learn best (books, video, doing, teaching)
  - Their plan to stay consistent with coding
  - How they’ll handle setbacks and frustration
- Play/Discuss this mindset video during group:Growth Mindset Video: https://www.youtube.com/watch?v=KUWn_TJTrnU
- Play/Discuss Agile overview if time allows:Explain Agile's focus on flexibility, iteration, feedback
- Review public learning and how it helps with career building
- Encourage sharing goals and mindset struggles with the group
- I also emphasize that the Python course has a lot of work in it, especially the capstones.
